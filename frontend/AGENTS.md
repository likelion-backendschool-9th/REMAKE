# REMAKE Frontend — Agent Guide

Rules for AI coding agents (Claude Code, Codex, etc.) working in `frontend/`. Follow them together with the root `AGENTS.md`.

Korean translation for developers: [`docs/developer/frontend-agent-guide.md`](../docs/developer/frontend-agent-guide.md)

## Read first

- Before starting, read [blueprint.md](./blueprint.md) for the tech stack, folder structure, routes, and data flow.
- If you need a structure or library that differs from blueprint.md, ask a human before changing code.

## Required rules

- Use **pnpm** only. Do not use `npm`, `yarn`, or `npx` (use `pnpm dlx`, `pnpm exec`).
- Run commands from `frontend/`. The git root is one level up (`REMAKE/`).
- **No Tailwind.** Write styles only with CSS Modules (`*.module.css`) and the CSS variables (design tokens) in `src/app/globals.css`. Do not add Tailwind, shadcn/ui, styled-components, emotion, or other styling libraries.
- Handle server data only with TanStack Query. Keep Zustand for minimal client state such as login info.
- Call APIs through `src/lib/api/client.ts` (openapi-fetch). `src/lib/api/schema.d.ts` is generated by `pnpm gen:api`; never edit it by hand.
- Do not reimplement backend features as Next Route Handlers or Server Actions. Business logic belongs to the Spring backend.
- Read environment variables only in `src/lib/env.ts`. When adding a variable, also add it to `.env.example`.
- Use Solar icons only (`@solar-icons/react/<style>`). Do not add lucide or any other icon library.
- For dates, use the `dayjs` exported from `src/lib/dayjs.ts` (ko locale configured).
- Build forms with React Hook Form + Zod (`@hookform/resolvers/zod`).
- If a backend API does not exist yet, add an MSW handler in `src/mocks/handlers.ts` and develop against it.

## Where code goes

- Keep routes (`src/app/**/page.tsx`) thin; put real UI and logic in `src/features/<feature>/`.
- Code used by one feature stays in that feature folder; code used by two or more features moves up to `src/components`, `src/hooks`, or `src/lib`.
- Do not import another feature's internal files; import through that feature's `index.ts`.
- Use the `@/` alias for imports (`@/*` → `src/*`).

## After changes

All of these must pass after a change:

```bash
pnpm lint
pnpm typecheck
pnpm build
```

- ESLint rules live in `eslint.config.mjs` (import sorting, type imports, no direct `dayjs` / `process.env`, no cross-feature internal imports, etc.). Use an `eslint-disable` comment only together with a stated reason.
- Prettier handles formatting. Husky + lint-staged run automatically on commit. Never skip the hook with `--no-verify`.
- Branches, commits, and PRs follow the Git convention in the root `AGENTS.md` (commit types: `feat`, `fix`, `chore`, `docs` only; every commit has a body).
