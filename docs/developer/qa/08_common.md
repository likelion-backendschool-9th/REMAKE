## COM. 공통·비기능

담당: 영역 전체(이준호 공통 규칙, 김종수 `global`, 배포 담당). 화면·API가 특정 영역에 속하지 않고 모든 API·화면에 걸리는 규칙, 배포·보안·이벤트 공통 동작, 영역 사이를 묶는 동시성·핵심 흐름 회귀 세트를 모았다.
**구현 상태(2026-11-24 기준)**: 공통 에러 응답·`GlobalExceptionHandler`·`traceId`, JWT 쿠키 보안, 백엔드·프론트 CI·CD(블루·그린 배포)가 있다. 이벤트 수집 API(56)·클라이언트 헤더 활용·오프라인·PWA 갱신은 구현 상태를 확인하며 실행한다.
v3에서 사라진 것: `Idempotency-Key`, `OCR_LIMIT_EXCEEDED`, 푸시 알림 시나리오(기기 푸시 없음), 어드민 화면, `CONCURRENT_UPDATE`·`INVALID_UNIT`·`INGREDIENT_HAS_LOGS`.
