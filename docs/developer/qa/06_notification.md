## NOTI. 알림 (이상호)

화면 코드: `notification_list`(p6 알림). 상단 알림 띠는 모든 탭 화면에 있다.
API: 43 알림 요약(띠), 44 알림 목록. 정기 작업: 소비기한 알림(매일 오전 9시 KST), 알림 정리(매일 새벽, 30일).
**구현 상태(2026-11-24 기준)**: 소비기한 알림 정기 작업, 알림 정리 작업, API 43·44가 구현돼 있다(#82). 식단표 완성·실패 알림(`MEAL_PLAN_*`)은 식단표 생성 작업이 구현돼야 만들어진다. 화면(#110)은 마크업만 있고 연동 전이다.
v3에서 사라진 것: 웹 푸시·`push_subscriptions`, 영수증 완료 알림(`RECEIPT_DONE`), 개별 읽음·모두 읽음 버튼, 읽음 처리 API, 알림 시각·기준일 설정, 어드민 API.
