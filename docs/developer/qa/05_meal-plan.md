## MEAL. 주간 식단표 (한윤수)

화면 코드: `meal_plan_calendar`(p5 달력·바텀 시트·⋮ 시트), `meal_plan_setup`(생성 설정), `meal_plan_overlap_modal`(겹침 경고, 대기).
API: 38 생성(비동기), 39 달력, 40 날짜별 식단, 41 칸 삭제, 42 칸 레시피 교체. 알림: `MEAL_PLAN_COMPLETED`·`MEAL_PLAN_FAILED`.
**구현 상태(2026-11-24 기준)**: 도메인 클래스(`MealPlan`·`MealPlanSlot`·`SlotIngredient`)만 있고 API·서버 작업은 구현 전(#78·#79·#80 진행 전). 전부 **막힘**으로 시작한다.
v3에서 사라진 것: 식단 로딩·실패 전용 화면(완료·실패는 앱 안 알림으로 알린다), 빈 끼니에 직접 넣기, 칸 상세 나중 생성, `meal_plan_slot_ingredients`, "참고용 식단" 문구, 의료 목적·칼로리 목표.
