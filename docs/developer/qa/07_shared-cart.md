## CART. 장바구니 (최유리)

화면 코드: `cart_list`(p7 장바구니: 일반·삭제 모드·수량 변경 시트·빈 화면).
API: 45 목록, 46 수량 변경, 47 냉장고로 옮기기, 48 선택 삭제. 담기는 API가 아니라 UseCase(`AddCartItemsUseCase`)로만 일어난다(식단표 생성 · 내 레시피 저장 · 공유 레시피 저장). 영수증 선택 차감은 `DeductCartItemsUseCase`(RCP-41~48).
**구현 상태(2026-11-24 기준)**: 차감 UseCase와 저장 기반(#219)만 있다. 목록·수량 변경·삭제·냉장고 이동 API(#89)와 담기 UseCase는 구현 전이라 해당 시나리오는 **막힘**으로 시작한다. 화면(#216)은 마크업만 있다.
v3에서 사라진 것: 직접 담기, 레시피 묶음(`group_name`)·`meal_plan_id`, 이름만으로 자동 삭제, 재저장 시 수량 덮어쓰기, 외부 쇼핑몰 이동·결제.
**미결**: 단위 환산(같은 종류 단위 사이), 같은 슬롯의 레시피 교체·덮어쓰기 때 출처 연결을 해제하는 구체 순서.

## SHARE. 공유 공간·랭킹 (최유리)

화면 코드: `recipe_ranking`(p4.1.4 이번 주 레시피 랭킹), `shared_write`(p4.1.1.1 공유 작성), `shared_detail`(p4.1.4.1), `shared_report`(신고 시트). 레시피 탭의 "금주의 레시피" TOP 3 카드는 `recipe_home`.

**구현 상태(2026-11-24 기준)**: 51(공유·사진 저장), 52(상세), 55(신고), 사진 조회가 구현됨(#86, #214, #64). 49·50(TOP 3·랭킹), 53·54(공유 저장·취소), 주간 순위 기록·보상 작업과 `generation_quota_grants`는 구현 전이라 **막힘**으로 시작한다.
