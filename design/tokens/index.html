Remake 디자인 토큰

v2.0.0 · 2026-11-20 · 피그마 REMAKE 파일의 로컬 변수 24개, 페인트 스타일 2개, 모바일 텍스트 스타일 6개를 이름 그대로 옮겼습니다.

원칙: 피그마 디자인이 최우선
  1. 토큰은 피그마에 정의된 변수·스타일만 이름 그대로 옮긴 것입니다. 값을 합치거나 4pt 등에 억지로 맞추지 않습니다.
  2. 개발할 때는 피그마 프레임(Dev Mode)을 읽고, 변수가 걸린 값은 같은 이름의 토큰을, 변수가 없는 값(간격·반경·그림자·글래스 등)은 프레임 값을 그대로 씁니다.
  3. 토큰과 피그마가 다르면 피그마를 따르고, 차이는 토큰에 반영합니다.
  4. 예외는 기능상 꼭 필요한 것만 둡니다(아래 표).
