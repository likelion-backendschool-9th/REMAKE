Remake 디자인 토큰

v3.1.0 · 2026-11-23 · Figma etTm84sh4aA60z6BmOwM3i '디자인 시스템' 페이지 > '0. 기초' (node 5761:2324, Remake 디자인 시스템 v1 2026-11-22)

원칙: 피그마 디자인이 최우선
  1. 토큰은 피그마 디자인 시스템(0. 기초)에 정의된 변수·스타일만 이름 그대로 옮긴 것입니다. CSS 변수 이름은 피그마 Dev Mode의 코드 이름과 같습니다.
  2. 개발할 때는 피그마 프레임(Dev Mode)을 읽고, 변수·스타일이 걸린 값은 같은 이름의 토큰을, 걸리지 않은 값은 프레임 값을 그대로 씁니다.
  3. 토큰과 피그마가 다르면 피그마를 따르고, 차이는 토큰에 반영합니다.
  4. 예외는 기능상 꼭 필요한 것만 둡니다(아래 표).
